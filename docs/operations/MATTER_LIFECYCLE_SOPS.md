# Matter Lifecycle and SOP Framework

**Document ID:** LG-OPS-001  
**Status:** Proposed; implementation begins after G2  
**Owner:** Legal operations lead

Each SOP must define trigger, prerequisite, authorized role, command, state transition, required evidence, audit event, client-visible outcome, exception path, recovery action, and validation source.

| SOP family          | Minimum control                                                                     |
| ------------------- | ----------------------------------------------------------------------------------- |
| Intake and conflict | No standard matter opening before approved conflict state.                          |
| Engagement          | Acceptance is explicit, versioned, and distinct from payment.                       |
| Matter/proceeding   | Separate aggregates, ownership, restrictions, and closure conditions.               |
| Deadline/hearing    | Rule source and version, calculation evidence, confirmation, reminders, escalation. |
| Documents/evidence  | Version/provenance, review/publication state, custody where applicable.             |
| Communication       | Approved content class, delivery evidence, failed-delivery escalation.              |
| Finance             | Invoice/payment/reconciliation independence from legal state.                       |
| Closure/retention   | Checklist, legal hold, archival, destruction approval.                              |

This framework is deliberately not a legal opinion or a substitute for practitioner validation.
